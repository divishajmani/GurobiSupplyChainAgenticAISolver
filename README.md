# GurobiSupplyChainAgenticAISolver
# 📦 Dynamic Supply Chain Control Tower Agent

A multi-agent decision intelligence system built with **CrewAI**, **Google Gemini**, **Gurobi MILP**, and **Streamlit**.

## Features
- **Scenario Classification**: Automatically categorizes logistics requests (VRP, Network Flow, Facility Location, Inventory, Blending).
- **Dynamic Gurobi Code Generation**: Translates natural language requests into dynamic `gurobipy` execution scripts.
- **Data Ingestion**: Multi-modal support for CSVs, multi-sheet Excel files, JSON payloads, and synthetic benchmark data.
- **Visual Analytics**: Interactive network flow graphs and shadow price / dual value extraction.
- **Interactive Chatbot**: Post-optimization advisory chatbot with session context memory.
